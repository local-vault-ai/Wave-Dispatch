# wave-gate2

[[wave-gate]] retrained so that writing requests (stories, poems, emails, jokes) go to the [[Writer]] and requests to
make a game, app, website or tool go to the [[Code Bot]]. Used by [[Gate Bot Writer]] and [[Gate Bot Code]]: on its
tests the Code Gate is right 99.4% of the time and the Writer Gate catches 94% of writing requests (wave-gate: 58%).
[[Gate Bot Math]] and [[Gate Bot Graph]] stay on [[wave-gate]], which is better at those. Back to [[AI Bots]].
